Architecture & Methodology

The Mathematical Foundation

Grounded in graph representation learning, linear requirement vector projections, and categorical entropy penalization.

1. Hybrid Linear Score Blending

Ranking Model

Final compatibility combines explicit skill requirement weights ($S_{\text{ML}}$) with topological graph affinity ($S_{\text{GNN}}$), with category saturation penalties ($\lambda = 0.15$):

# Hybrid Compatibility Formula:
Score_hybrid(u, c) = (0.40 × Score_ML) + (0.60 × Score_GNN)
# Maximal Marginal Relevance Penalty:
Score_final(c) = Score_hybrid(c) - (count(cat_c) × 0.15)
  • ML Skill Vector: $\text{SkillScore}(u, c) = \frac{\sum w_{c,s}}{\sum w_{total}} + \text{Bonus}_{\text{edu}} + \text{Bonus}_{\text{int}}$
  • Alternative Crosswalk: $S_{\text{sim}} = 0.40 S_{\text{gnn}} + 0.35 S_{\text{graph}} + 0.25 S_{\text{ml}}$
Link Prediction ROC-AUC: ≥ 0.88 Hit Rate@5: > 90%

2. PyG GraphSAGE Convolutions

Deep Learning

Inductive node representation learning through localized mean neighborhood aggregation across heterogeneous graph topologies:

# Layer-k Inductive Node Aggregation:
h_N(v)^(k) = MEAN({h_u^(k-1), ∀u ∈ N(v)})
h_v^(k) = σ(W^(k) • [h_v^(k-1) || h_N(v)^(k)])
# Composite Student Vector & Cosine Affinity:
Score_GNN(u, c) = (z_student • z_career) / (||z_student|| • ||z_career||)
  • Inductive Architecture: 2-Layer SAGEConv (64 → 48 → 32 dimensions)
  • Training Objective: Binary Cross-Entropy with Logits (BCE)
Latent Embedding Size: 32 Dimensions Framework: PyTorch Geometric

Our engine computes two orthogonal metrics: (1) An explicit Content-Based ML Vector score (40% weight) assessing direct skill requirement weights, education degrees, and domain interests; and (2) A PyG GraphSAGE Inductive Embedding cosine similarity (60% weight) that aggregates multi-hop graph topology. The blended score is then regularized using Maximal Marginal Relevance (MMR) to promote domain diversity.

The platform is designed specifically for students! Even with zero prior skills, you can select your academic degree, branch, and preferred domain interests (e.g. AI, Web, Cloud). The GNN utilizes inductive inference to predict prospective entry-level pathways and generates a Phase-1 foundational study roadmap.

The Knowledge Graph contains directed prerequisite edges ($s_a \to s_b$) between foundational and advanced skills (e.g., Python → Machine Learning → Deep Learning → PyTorch). When generating a learning roadmap, NetworkX performs a Directed Acyclic Graph (DAG) topological sort so you never encounter an advanced concept before its dependencies.

Alternative Pathways calculate multi-modal similarity ($S_{sim} = 0.40 S_{gnn} + 0.35 S_{graph} + 0.25 S_{ml}$) to identify adjacent industry roles. It automatically partitions competencies into shared skills vs. additional skills and estimates transition effort as Low, Medium, or High.
